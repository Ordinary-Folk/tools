How to install

KBar button

  1. Add a button: Run JSX File.
  2. Pick the script's loader (the file without a version number). It always runs the newest build.
  3. Icon > Image > PNG from the pack.

Dockable panel

Copy the loader into AE's Scripts/ScriptUI Panels, restart. It's in the Window menu.

Dropbox

Right-click the shelf folder > Make Available Offline, once.

Download the KBar icon pack

Versions and dates come straight from the Dropbox folders; blurbs are written by hand in the hub repo (scripts/catalog.json).
