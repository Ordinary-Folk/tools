How to install

KBar button

  1. KBar panel > settings > add a button, type Run JSX File.
  2. Point it at the script's loader on the shelf (the file without a version number). The loader always runs the newest build, so updates need nothing from you.
  3. Icon > Image > pick the PNG from the icon pack below. Close and reopen the KBar panel to see it.

Dockable panel

  1. Copy the loader into Scripts/ScriptUI Panels inside the After Effects app folder (needs an admin password once).
  2. Restart AE; it then sits in the Window menu.

Dropbox

Right-click the shelf folder in Finder > Make Available Offline once, so AE never waits on a download.
